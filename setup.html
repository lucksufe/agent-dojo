安装与配置

这一章只做一件事：让你的电脑具备「说一句话就生成脚本」的能力。全流程大约 15 分钟，配置模型 Key 的部分在下面第三节。

1. 下载与安装

下载 Trae

访问 trae.cn（国内版）或 trae.ai（国际版），下载 Windows / macOS 安装包。国内版注册更简单，模型服务在国内，网络更稳，建议优先选国内版。

安装并登录

一路默认安装即可。首次启动会要求登录，用手机号或邮箱注册一个账号，跟着引导走完（选择主题、是否导入已有编辑器设置），这些选项都不影响后续使用。

打开一个文件夹作为工作区

点「打开文件夹」，新建一个空文件夹专门放这次任务的资料，例如 D:\AI脚本\第一个脚本。把要处理的文件复制进去。

✓

单独建文件夹是整份指南里最值得养成的习惯。它决定了 Agent 能看到什么、能改什么，出问题时也最容易被还原。

2. 认识界面

Trae 的界面和常见编辑器类似，分成四块。你只需要记住下面这几个位置：

区域位置用来做什么
文件区左侧显示你打开的工作区里有哪些文件，点一下就能看内容
编辑区中间查看和修改文件，AI 生成的脚本会出现在这里
AI 对话区右侧你在这里提需求，它在这里汇报进度、请求权限
终端下方脚本真正运行的地方。AI 会自动往里输入命令，你也可以自己敲
i

找不到设置？点右上角的头像或齿轮图标；快捷键 Ctrl + , 通常也可以直接打开设置。

3. 两种模式：Chat 与 Builder

Trae 的对话框通常提供两种模式，理解区别就不会用错：

Chat 模式

问答式

你说，它答。只给建议和代码片段，不会自动改你的文件。适合：问概念、让它解释一段代码、讨论方案。

Builder 模式

执行式（Agent）

它会自己读文件、建文件、跑命令、改错，直到任务完成。写脚本就用这个。每一步写入前会请求你的确认。

如果你只是想「先把需求聊清楚再动手」，可以在 Chat 里讨论，确定方案后切到 Builder 说一句「按刚才的方案执行」。

4. 添加自己的模型 Key（重点）

为什么需要自己的 Key

Trae 登录后会附带一定的免费额度，够你熟悉功能。但下面几种情况，需要接入自己的模型服务：

  • 免费额度用完了，继续用要排队或付费。
  • 公司有统一采购的模型服务，IT 给了你 Key 和接口地址。
  • 你希望用某个特定模型，比如代码能力更强、或者更便宜的。
  • 数据合规要求，必须走公司指定的通道。

动手前，先准备三样东西

要准备它是什么去哪拿
API Key 一串很长的字符，相当于「密码」，一般以 sk- 开头 模型服务商的控制台 → API Keys → 创建
Base URL
接口地址		 请求发往哪个服务器，通常以 /v1 结尾 服务商的「API 文档」里，找「兼容 OpenAI」那一节
模型 ID
模型名称		 要用哪个模型，比如 deepseek-chat 服务商的「模型列表」页面

这三样东西通常都在服务商控制台的「API Key / 密钥管理」和「开发文档」里，五分钟能找齐。如果公司统一采购，直接问 IT 要这三个值。

填写步骤

打开设置 → 模型

点右上角头像或齿轮进入设置，在左侧找到「模型 / Models」这一类选项。不同版本的菜单位置和叫法会略有差别，关键是找和 Model 相关的设置页。

选择「添加模型 / 自定义模型」

点「+ 添加」或「Add Model」。如果服务商列表里有你用的那家，直接选；没有就选 OpenAI 兼容 / OpenAI Compatible（绝大多数国内厂商都支持这种格式）。

粘贴 API Key

把 Key 完整粘进去。注意前后不要带空格，也不要漏掉中间的字符——这是失败率最高的一步。

填写 Base URL

照抄服务商文档里的地址。不要自己加路径，比如文档给的是 https://api.deepseek.com/v1，就原样填，不要再补 /chat/completions。

填写模型 ID 并保存

填服务商文档里的确切名称，区分大小写、区分版本号。保存后一般会有「测试连接」按钮，先点它。

在对话框里选中这个模型

回到对话区，点模型下拉框，选中刚添加的那个，可以设为默认。之后新建对话就会自动用它。

!

Key 就是密码。不要截图发群、不要写进脚本文件、不要上传到网盘或代码仓库。如果怀疑泄露，立刻去服务商控制台删除这个 Key 并重新创建——旧 Key 会立即失效。

6. 怎么确认真的接通了

配置成功后，别急着写脚本。先发一句最简单的话做冒烟测试：

测试模型是否可用
你好，请用一句话回答：1 加 1 等于几？

如果秒回「2」，说明链路是通的。如果没反应、报错或一直转圈，看下一节的排查表。

接着再测一次「它能不能看到文件」——这一步能确认工作区选对了：

测试工作区是否正常
请列出当前工作区里有哪些文件，只列文件名，不要修改任何东西。

7. 准备运行环境

大多数小脚本用 Python 写，处理 Excel、Word、图片也靠 Python 的现成库。你不需要学会写，但电脑上得装好 Python。

先让 Agent 帮你检查

直接发这句话给它
请在终端里检查这台电脑是否已经安装 Python，告诉我版本号。
如果没装，给我 Windows 上最简单的安装方法，一步一步说，不要让我自己找文档。

没装就装一个

到 python.org 下载最新版，安装时务必勾选「Add Python to PATH」，这一步漏了后面会很麻烦。装完重启一下 Trae。

缺什么库，让它自己装

处理 Excel 需要 openpyxl，处理 Word 需要 python-docx，处理图片需要 Pillow。不用自己记，直接说「需要什么库你自己装」。它会在终端执行安装命令，你点同意即可。

8. 配置失败怎么排查

报错信息通常很直白，对照下面这张表，八成能自己解决：

你看到的提示大概率原因怎么解决
401 Unauthorized
Invalid API Key		Key 错了、过期，或前后多了空格回控制台重新复制一次，粘贴后检查首尾
404 Not FoundBase URL 写错了，多写或少写了 /v1一字不差地照抄文档里的地址
model not found
invalid model		模型 ID 拼错、大小写不符用文档里的确切写法，别自己简写
timeout / 一直转圈网络不通、需要代理，或公司网络拦截换国内服务商；检查代理设置；换网络试
402 / insufficient balance账户余额不足充值，或换一个可用的 Key
能连上但回答很笨、说不全选了轻量模型，或上下文被塞太满换主力模型；新开一段对话重新交代
✓

搞不定时，把完整报错原文复制给 Agent，说「这是我配置模型时遇到的报错，帮我判断是哪一步错了」。它对这些错误码很熟，往往一句话就能指出来。
