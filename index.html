01这些事，可能正在消耗你

它们有个共同点：规则明确、重复、每次都要花十几分钟到一整天——但又不值得专门找 IT 排期开发。

文件批量重命名

下载了一堆命名混乱的附件，要统一加日期、删掉「最终版」「副本」这类词。

多张表格合并

12 个月的分表、20 个门店的日报，要合成一张总表再做透视。

文档信息提取

几十份合同或申请单，要抄出编号、金额、日期，登进 Excel。

图片批量处理

几百张商品图要统一压缩到指定尺寸，还要分文件夹存放。

格式来回转换

CSV 转 Excel、Word 转文本、PDF 拆页，一次几十个文件。

定时整理归档

每天把下载文件夹按类型、按月份自动归类，月底打包。

i

为什么以前做不了？这类需求的代码量往往只有几十行，找开发排期不划算，自己学编程又要几周。而 Agent 能把「说一句话」直接变成「可运行的脚本」，正好填上这个空档。

02你要做的，只有三步

装好工具，接上模型

下载 Trae，登录后选一个模型。如果公司有指定的模型服务，或者免费额度不够用，就填入自己的 API Key。这一步只做一次。

把需求讲清楚

告诉它：要什么结果、数据在哪、输出成什么样、特殊情况怎么处理。不用写代码，用你平时跟同事交代事情的方式说就行。

小范围试跑，再放开用

让它先拿 3 个文件试，确认结果对，再处理全量。跑完抽查几条，没问题就存下来，下次双击运行。
